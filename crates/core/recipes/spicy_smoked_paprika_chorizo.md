# Spicy Smoked Paprika Chorizo

## Ingredients

| Ingredient | Quantity | Prep | Notes |
| --- | --- | --- | --- |
| Spanish Chorizo | 225g |  | ideally good quality |
| Red Onions | 4 | finely diced |
| Garlic Cloves | Several | fined diced or crushed in a press |
| Pointed Red Peppers | 2 | sliced |
| Carrots | 2-3 | diced |
| Fresh Spinach | 100g | torn | frozen would also work |
| Tinned Tomatoes | 3 |
| Tomato Paste | 4 Inches |
| Red Wine | 10-20CL |  | something in the £5-10 range |
| Smoked Paprika | Several teaspoons |
| Olive Oil |
| Chilli Flakes |
| Honey | 2 tsp |  | anything but that Rowse shit |
| Dried Oregano | 1 tbsp |
| Stick of Cinnamon | 1 |  | Ground also works |
| Pitted Black Olives | 6 tbsp | halved |
| Cannellini beans | 1 400g tin | drained and rinsed | Optional |
| Celery |  | chopped into 1cm pieces | Optional |
| Whole Cloves | 2-3 |  | Optional |
| Mascarpone | 2 tbsp |  | Optional |

## Method

1. Cut the chorizo into half centimeter thick semi-circles.
2. Add the oil and smoked paprika to a wide pan.
3. Cook the carrots and celery on a medium to high heat for a minute or so. Stir regularly to avoid sticking.
4. Add the red onions and garlic then cook for minute.
5. Stir in the chorizo, peppers and tomato paste then cook for a few more minutes.
6. Add the pasata, tinned tomatoes, cloves, chilli flakes, red wine, oregano, cinamon stick, and honey. If the pan is looking full then wait until the mixure has reduced before adding the rest of the tinned tomatoes/wine.
7. Wait until bubbling then turn down the heat and simmer for at least 20 minutes.
8. Stir in spinach, mascarpone and cannellini beans.
9. Serve with pasta

## Notes

- If your chorio is very spicy you might not need any chilli flakes. Similarly if you use chilli oil.
- This dish tastes best if you leave it to cool then reheat it.
- You could try serving this dish over grilled aubergines.
