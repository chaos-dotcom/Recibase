# Mushroom Stroganoff

## Ingredients

| Ingredient | Quantity | Prep | Notes |
| --- | --- | --- | --- |
| Butter |
| Large Onion | 1 | sliced |
| Brown Mushrooms | 250g | sliced |
| Shiitake or Porchini Mushrooms | Some |
| Vegetable or Mushroom stock cube | 1 |
| Soured Cream | 350ml |
| Plain Flour | 3 tbsp |
| Salt |
| Black Pepper |
| Garlic | 1 clove | diced | Optional |
| Nutmeg |  |  | Optional |
| Brandy |  |  | Optional |
| Marjoram |  |  | Optional |
| Worcestershire sauce |  |  | Optional |

## Method

1. Chop the shiitake or porchini mushrooms into large pieces
2. Boil the kettle then use as little water as possible to disolve the cube in a jug.
3. Melt butter in a large frying pan then soften the onion with the garlic.
4. Turn up the heat and add the brown mushrooms. Cook for a minute or so.
5. Add the Shiitake or Porchini Mushrooms and cook for a minute more.
6. Turn down the heat then stir in the soured cream, being careful not to let it boil.
7. Stir in the vegetable stock until you have a creamy sauce that isn't too watery. You might not need all the stock. Sift in plain flour, a small bit at a time, if needed.
8. Add salt, black pepper, nutmeg, Worcestershire sauce, marjoram and brandy to taste.
9. Serve with rice.

## Notes

- You can substitute Shiitake or Porchini mushrooms for their dried equivalents.
  Pots of dried forest mushrooms also work. Try softening the mushrooms in the stock.
